# Báo cáo Bài 1: Khởi tạo Local Repository và Cấu hình danh tính

## 1. Các lệnh đã sử dụng:
- Khởi tạo repo: `git init`
- Cấu hình tên: `git config --local user.name "Ho Khanh Linh"`
- Cấu hình email: `git config --local user.email "hokhanhlinh2006@gmail.com"`
- Add file: `git add README.md`
- Commit: `git commit -m "Khoi tao bai tap 1 va cau hinh local"`
